# @nifelux/brand
Shared Colon AI brand assets: the animated logo intro (drop, ripple, flame, COLON) and the logo marks.

| Path | What it is |
|---|---|
| `css/colon-intro.css`, `js/colon-intro.js` | The intro, played once per browser session |
| `assets/colon-mark.svg`, `assets/colon-admin-mark.svg` | Logo marks (the apps' SVG favicons) |

Deployed under `/v<version>/packages/brand/` by `scripts/deploy/build-docroot.sh`; the unversioned
`/brand/colon-intro.css|js` URLs older pages used are kept as a mirror.
